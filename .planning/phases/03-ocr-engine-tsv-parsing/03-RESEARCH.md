## Summary

Phase 3 completes the `internal/ocr` package that Phase 1 scaffolded. The CLI backend is the default and must shell out to the installed Tesseract 5.5.0 binary, capturing its TSV output on stdout and parsing it into `Word` structs. The gosseract backend is an optional, build-tagged alternative that links against `libtesseract` via CGO and uses `GetBoundingBoxesVerbose()`. Both must satisfy the existing `ocr.Engine` interface and `Word{Text, Confidence, X0, Y0, X1, Y1}` contract.

The single biggest correctness risk is TSV parsing: Tesseract emits 12 columns but rows are not strictly rectangular — empty `text` fields may or may not carry a trailing tab, and levels 1-4 carry `conf == -1`. Using `encoding/csv` with `Comma='\t'` and `FieldsPerRecord=-1` (verified in this session) handles both cleanly; `strings.Split` does not. The second risk is environment wiring: `TESSDATA_PREFIX` must point at the `tessdata` directory itself (not its parent) for this Tesseract build, and must be derived from the tesseract binary location when unset.

**Primary recommendation:** Implement an exported `ParseTSV(io.Reader) ([]Word, error)` (pure, easily unit-tested), a CLI `Recognize` that runs `tesseract <img> stdout tsv` with `cmd.Env` carrying `TESSDATA_PREFIX`, and a tagged gosseract `Recognize` using `GetBoundingBoxesVerbose()`. Keep the default build CGO-free; add `github.com/otiai10/gosseract/v2 v2.4.1` to `go.mod` (already cached) under the build tag.

### Pattern 1: Pure TSV parser (testable without Tesseract)
**What:** Export `ParseTSV(io.Reader) ([]Word, error)` so tests feed golden/edge-case TSV directly; `Recognize` becomes a thin exec wrapper.
**When to use:** All TSV parsing; never parse inside `Recognize` ad hoc.
**Example:**
```go
// Source: verified encoding/csv behavior (this session)
func ParseTSV(r io.Reader) ([]Word, error) {
    cr := csv.NewReader(r)
    cr.Comma = '\t'
    cr.FieldsPerRecord = -1  // variable field counts
    cr.LazyQuotes = true

    records, err := cr.ReadAll()
    if err != nil {
        return nil, fmt.Errorf("ocr: read tsv: %w", err)
    }

    words := make([]Word, 0)
    for _, rec := range records {
        if len(rec) == 0 {
            continue
        }
        // Header row: first field is "level"
        if strings.TrimSpace(rec[0]) == "level" {
            continue
        }
        if rec[0] != "5" {
            continue
        }
        if len(rec) < 11 {
            continue // malformed row
        }
        conf, err := strconv.ParseFloat(strings.TrimSpace(rec[10]), 64)
        if err != nil {
            continue
        }
        if conf < 0 {
            continue // ignore -1 (and any negative)
        }
        left, err1 := strconv.Atoi(strings.TrimSpace(rec[6]))
        top, err2 := strconv.Atoi(strings.TrimSpace(rec[7]))
        w, err3 := strconv.Atoi(strings.TrimSpace(rec[8]))
        h, err4 := strconv.Atoi(strings.TrimSpace(rec[9]))
        if err1 != nil || err2 != nil || err3 != nil || err4 != nil {
            continue
        }
        text := ""
        if len(rec) >= 12 {
            text = rec[11]
        }
        if strings.TrimSpace(text) == "" {
            continue // skip empty-text words
        }
        words = append(words, Word{
            Text:       text,
            Confidence: conf,
            X0:         left,
            Y0:         top,
            X1:         left + w,
            Y1:         top + h,
        })
    }
    return words, nil
}
```

### Pattern 2: CLI backend
**What:** Resolve binary + tessdata, run tesseract with `stdout tsv`, parse stdout.
**When to use:** Default backend.
**Example:**
```go
// Source: verified against installed Tesseract 5.5.0 (this session)
const DefaultTesseractPath = `C:\Program Files\Tesseract-OCR\tesseract.exe`

type cliEngine struct {
    tesseractPath string
}

func (c *cliEngine) Recognize(imagePath string) ([]Word, error) {
    bin := c.tesseractPath
    if bin == "" {
        bin = DefaultTesseractPath
    }
    if _, err := os.Stat(bin); err != nil {
        return nil, fmt.Errorf("ocr: tesseract binary not found %q: %w", bin, err)
    }

    // OCR-04: set TESSDATA_PREFIX if unset (points at tessdata dir itself).
    if os.Getenv("TESSDATA_PREFIX") == "" {
        derived := filepath.Join(filepath.Dir(bin), "tessdata")
        os.Setenv("TESSDATA_PREFIX", derived) // startup-time; single-threaded
    }

    cmd := exec.Command(bin, imagePath, "stdout", "tsv")
    // Ensure child sees the prefix even if os.Setenv races; pass explicitly.
    if os.Getenv("TESSDATA_PREFIX") != "" {
        cmd.Env = append(os.Environ(), "TESSDATA_PREFIX="+os.Getenv("TESSDATA_PREFIX"))
    }
    var stdout, stderr bytes.Buffer
    cmd.Stdout = &stdout
    cmd.Stderr = &stderr
    if err := cmd.Run(); err != nil {
        return nil, fmt.Errorf("ocr: tesseract failed: %w (stderr: %s)", err, strings.TrimSpace(stderr.String()))
    }
    return ParseTSV(bytes.NewReader(stdout.Bytes()))
}
```

### Pattern 3: gosseract backend (build-tagged)
**What:** Use `GetBoundingBoxesVerbose()` and map `BoundingBox.Box` (image.Rectangle) to Word bbox.
**When to use:** Only with `-tags gosseract` and CGO.
**Example:**
```go
//go:build gosseract
// Source: otiai10/gosseract v2.4.1 client.go (verified in module cache)
package ocr

import (
    "fmt"
    "os"
    "path/filepath"
    "strings"

    gosseract "github.com/otiai10/gosseract/v2"
)

type gosseractEngine struct {
    tesseractPath  string
    tessdataPrefix string
}

func newGosseractEngine(cfg Config) (Engine, error) {
    prefix := cfg... // see below
    if prefix == "" {
        prefix = os.Getenv("TESSDATA_PREFIX")
    }
    if prefix == "" && cfg.TesseractPath != "" {
        prefix = filepath.Join(filepath.Dir(cfg.TesseractPath), "tessdata")
    }
    return &gosseractEngine{tesseractPath: cfg.TesseractPath, tessdataPrefix: prefix}, nil
}

func (g *gosseractEngine) Recognize(imagePath string) ([]Word, error) {
    client := gosseract.NewClient()
    defer client.Close()

    if err := client.SetImage(imagePath); err != nil {
        return nil, fmt.Errorf("ocr: gosseract set image: %w", err)
    }
    if g.tessdataPrefix != "" {
        if err := client.SetTessdataPrefix(g.tessdataPrefix); err != nil {
            return nil, fmt.Errorf("ocr: gosseract set tessdata prefix: %w", err)
        }
    }
    boxes, err := client.GetBoundingBoxesVerbose()
    if err != nil {
        return nil, fmt.Errorf("ocr: gosseract recognize: %w", err)
    }

    words := make([]Word, 0, len(boxes))
    for _, b := range boxes {
        text := strings.TrimSpace(b.Word)
        if text == "" {
            continue
        }
        if b.Confidence < 0 {
            continue
        }
        words = append(words, Word{
            Text:       b.Word,
            Confidence: b.Confidence,
            X0:         b.Box.Min.X,
            Y0:         b.Box.Min.Y,
            X1:         b.Box.Max.X,
            Y1:         b.Box.Max.Y,
        })
    }
    return words, nil
}
```

Note: `gosseract.NewClient()` defaults to `Languages: ["eng"]` and `Trim: true`; `SetTessdataPrefix` must be called before `SetImage`? In gosseract, `SetTessdataPrefix` only sets the field and calls `flagForInit()`; `SetImage` does not init. Init happens lazily in `GetBoundingBoxesVerbose`. So order is flexible, but set prefix before OCR call. Fine.

### Anti-Patterns to Avoid
- **`strings.Split(line, "\t")` for TSV:** drops trailing empty fields; use `encoding/csv`.
- **Treating header as a word:** skip rows where `rec[0]=="level"`.
- **Accepting `conf == -1`:** these are layout rows; filter `conf < 0`.
- **Assuming 12 fields always:** handle `len(rec) < 12` (text missing) by treating text as empty.
- **PDF-point coordinates in edit pipeline:** keep image pixel space (x0=left, y0=top).
- **Global `os.Setenv` for tessdata in concurrent paths:** acceptable at startup; for per-call safety pass via `cmd.Env`.
- **Importing gosseract in default build:** keep behind `//go:build gosseract` on every file including tests.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| TSV parsing | Custom line splitter | `encoding/csv` with tab delimiter | Handles quoting, CRLF, empty trailing fields. |
| Tesseract invocation | Shell string | `exec.Command` with arg slice | Avoids injection and quoting issues. |
| Bbox from gosseract | Manual struct | `b.Box.Min/Max` (image.Rectangle) | Already provided. |

**Key insight:** Tesseract's TSV is not rectangular in naive parsers; `encoding/csv` with `FieldsPerRecord=-1` is the robust, stdlib solution.

## Common Pitfalls

### Pitfall 1: TSV header and empty lines
**What goes wrong:** First row is the header (`level page_num ... text`); blank lines may appear between pages.
**Why it happens:** Tesseract always emits a header; multi-page output includes blanks.
**How to avoid:** Skip rows where `rec[0]=="level"`; `encoding/csv` skips blank lines automatically (verified).
**Warning signs:** Off-by-one column reads; "level" parsed as a word.

### Pitfall 2: `-1` confidence
**What goes wrong:** Levels 1-4 carry `conf=-1` and empty text; naive filter leaks phantom words.
**How to avoid:** Only accept `level=="5"` and `conf>=0`.
**Warning signs:** Word count inflated; confidence -1 in output.

### Pitfall 3: Variable field count
**What goes wrong:** Rows with empty text may omit the trailing tab, yielding 11 fields instead of 12.
**How to avoid:** `FieldsPerRecord=-1`; require `>=11`; treat missing 12th as empty text.
**Warning signs:** `csv` error "wrong number of fields" if not set.

### Pitfall 4: TESSDATA_PREFIX points at parent vs tessdata dir
**What goes wrong:** Setting prefix to `C:\Program Files\Tesseract-OCR` makes Tesseract fail "Failed loading language 'eng'".
**Why it happens:** This Tesseract build expects the prefix to be the `tessdata` directory itself.
**How to avoid:** Derive `<bindir>/tessdata` and verify with a smoke run.
**Warning signs:** "couldn't load any languages".

### Pitfall 5: gosseract API name
**What goes wrong:** Plan references `GetTextBoxes`, which does not exist in v2.4.1.
**How to avoid:** Use `GetBoundingBoxesVerbose()`.
**Warning signs:** Compile error.

### Pitfall 6: CGO build-tag leakage
**What goes wrong:** Missing build tag compiles CGO into default build, breaking CGO-free CI.
**How to avoid:** `//go:build gosseract` on `gosseract.go` and any gosseract test files; run `go build ./...` and `go vet ./...` in default mode.
**Warning signs:** `cgo` errors on machines without headers.

### Pitfall 7: Text field internal spaces
**What goes wrong:** Trimming text could corrupt multi-token strings (rare in TSV words).
**How to avoid:** Keep `text` verbatim from CSV; only `strings.TrimSpace` for the emptiness check and conf/geometry fields.
**Warning signs:** Missing spaces in output words.
