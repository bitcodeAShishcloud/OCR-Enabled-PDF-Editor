## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| image path -> ocr | Caller-supplied image path crosses into os/exec (CLI) and CGO (gosseract). |
| TSV bytes -> ParseTSV | Tesseract output is parsed; malformed rows must not crash. |
| env -> process config | TESSERACT_PATH / TESSDATA_PREFIX drive binary and model location. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | imagePath argument | medium | mitigate | os.Stat existence check before exec; args passed as a slice to exec.Command (no shell, no injection). |
| T-03-02 | Tampering | TSV content | low | mitigate | encoding/csv robust parsing; unknown levels ignored; ParseFloat/geometry parse errors skipped. |
| T-03-03 | Tampering | TESSERACT_PATH / TESSDATA_PREFIX env | medium | mitigate | os.Stat existence check at config load (Phase 1) and in Recognize; no arbitrary execution beyond configured binary. |
| T-03-04 | Denial of Service | tesseract hang / huge output | medium | accept | Recognize uses exec.Command (no timeout in v1); timeout/cancellation deferred; surfaces errors. |
| T-03-05 | Information Disclosure | stderr in errors | low | accept | stderr included in wrapped error for debugging; no secrets expected. |
| T-03-SC | Tampering | package installs | high | mitigate | gosseract v2.4.1 and gg v1.3.0 approved in RESEARCH.md Package Legitimacy Audit; added via go get; default build stays CGO-free. |
</threat_model>
