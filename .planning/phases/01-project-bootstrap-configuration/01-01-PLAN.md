Import syscall; if it fails to compile on Windows, fall back to os.Interrupt only and note in the task output.

   Use log/slog JSON handler, encoding/json, context, errors, fmt, net/http, os, os/signal, strconv, syscall, time, and ocrpdf/internal/ocr (import path `ocrpdf/internal/ocr`).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> HTTP server | Untrusted HTTP requests reach the listener (only /healthz in this phase). |
| env -> process config | Environment variables drive paths/backend; misconfiguration can point at arbitrary files. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | OCR_BACKEND env var | medium | mitigate | Enum validation in loadConfig; only cli or gosseract accepted; invalid fails fast. |
| T-01-02 | Tampering | TESSERACT_PATH / FONT_PATH env vars | medium | mitigate | os.Stat existence check; fail fast with clear message; no arbitrary execution beyond configured binary (Phase 3 invokes it). |
| T-01-03 | Denial of Service | http.Server without timeouts | medium | mitigate | ReadHeaderTimeout 10s and IdleTimeout 60s set on http.Server. |
| T-01-04 | Denial of Service | PORT parsing | low | mitigate | strconv.Atoi + range check 1..65535; fail fast on invalid. |
| T-01-SC | Tampering | package installs | low | accept | No packages installed in Phase 1 (stdlib only); go.mod/go.sum untouched. |

</threat_model>
