internal/edit/edit.go: define `ToRGBA(img image.Image) *image.RGBA` (return as-is if already *image.RGBA, else draw onto a new RGBA), and `ParseColor(s string) (color.RGBA, error)` parsing `#RGB`/`#RRGGBB` (expand shorthand, validate length and hex digits, alpha 255, reject empty/non-#).

internal/edit/color.go: `luminance(c color.RGBA) float64` using 0.299/0.587/0.114. `SampleBackground(img *image.RGBA, bbox image.Rectangle, ring int) color.RGBA`: build an annulus by expanding bbox by ring (default 6 if <=0), intersect with image bounds, collect pixels in the outer region but outside bbox, skip pixels with luminance < 80 (ink), take per-channel median; if no samples return opaque white. `SampleTextColor(img *image.RGBA, bbox image.Rectangle, bg color.RGBA) color.RGBA`: collect bbox pixels with luminance < bgLum-30; if fewer than 5, fall back to the darkest 10% of all bbox pixels (minimum 1); take per-channel median; if none return opaque black. Include a small inline median helper using sort.Ints.

internal/edit/erase.go: `Erase(img *image.RGBA, bbox image.Rectangle, pad int, bg color.RGBA)`: clamp pad to >=0, intersect `bbox.Inset(-pad)` with image bounds, use `gg.NewContextForRGBA(img)`, SetColor(bg), DrawRectangle, Fill.

internal/edit/render.go: `FitFontSize(fontPath, text string, boxW, boxH float64) (float64, error)`: empty text returns 4; clamp hi to min(boxH, 200) with floor 4; binary search 40 iterations loading the face each iteration via `gg.LoadFontFace`, measuring width with `font.MeasureString` and height from `face.Metrics().Height/64`; accept candidates where width <= boxW and height <= boxH; return largest accepted (best starts at 4). `RenderText(img *image.RGBA, bbox image.Rectangle, text string, fontPath string, size float64, col color.Color) error`: if size <=0 call FitFontSize first; load face; compute baseline = bbox.Max.Y - Descent/64, clamp so baseline - Ascent/64 >= bbox.Min.Y; create gg context for the image, SetColor(col), LoadFontFace, DrawString at (bbox.Min.X, baseline).

internal/edit/edit_test.go: tracer test `TestEditTracer` that creates a 200x60 white RGBA, draws "John" in black with gg at 32pt, calls SampleBackground (expect near-white), Erase, FitFontSize for "Jane", RenderText, and asserts non-zero dark pixels afterward. Also `TestFitFontSize` (TEST-02): skip if `C:\Windows\Fonts\arial.ttf` missing; assert fitted size for "Jane" in a 100x40 box is between 4 and 40 and that measured height <= 40 and width <= 100; assert empty text returns 4 with nil error.
