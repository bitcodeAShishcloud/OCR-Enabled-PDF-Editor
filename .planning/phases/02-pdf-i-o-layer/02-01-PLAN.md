   - Blank imports for image decoders: image/png, image/jpeg, image/gif, golang.org/x/image/webp, github.com/hhrutter/tiff (so image.DecodeConfig can measure TIFF/WebP/PNG/JPEG/GIF).
   - `var pageFileRe = regexp.MustCompile("_(\\d+)_([A-Za-z]+)\\.[A-Za-z0-9]+$")`.
   - `func ExtractImages(ctx context.Context, pdfPath, outDir string) ([]string, error)`:
     * Reject empty pdfPath/outDir with a wrapped error.
     * Clean both paths with filepath.Clean.
     * MkdirAll outDir; remove any stale entries inside it (per-document reuse).
     * Call pdfcpu api.ExtractImagesFile with selectedPages nil and model.NewStatelessConfiguration(); wrap any error with context.
     * Obtain page count via api.PageCountFile; wrap error.
     * Read outDir entries; skip dirs; match each filename against pageFileRe; parse the page number; group paths by page.
     * For each page 1..pageCount, require at least one candidate; otherwise return an error stating the missing page.
     * Select the candidate via largestImage; append to result.
     * Return the slice (one path per page, in page order).
   - `func largestImage(paths []string) (string, error)`:
     * For each path, open it; call image.DecodeConfig; close. On decode failure, treat area 0 (so undecodable resources do not fail the whole extraction but lose selection priority); still use file size.
     * Stat the file for size.
     * Track best by: greater area; on equal area greater size; on equal size lexicographically smaller path.
     * Return best path or an error if no candidates.
   - Wrap all filesystem/pdfcpu errors with "pdfio:" context per D-07.

3. Create `internal/pdfio/build.go` (package pdfio) with:
   - `func BuildPDF(ctx context.Context, imagePaths []string, outputPath string) error`:
     * Reject empty imagePaths or outputPath with a wrapped error.
     * Clean outputPath with filepath.Clean; MkdirAll its parent directory.
     * PDF-03: os.Remove(outputPath); ignore os.IsNotExist; wrap other errors.
     * Open imagePaths[0]; image.DecodeConfig for width/height; close; wrap errors.
     * imp := api.DefaultImportConfig() (D-06); imp.PageDim = &types.Dim{Width: float64(w), Height: float64(h)} (D-05). Leave Pos as the default Full so the image fills the page.
     * Call api.ImportImagesFile with model.NewStatelessConfiguration(); wrap errors.
   - Blank imports for image/png and image/jpeg at minimum (for dimension decoding of common formats); also webp and tiff for parity.

4. Create `internal/pdfio/temp.go` (package pdfio) with:
   - `func NewTempDir(prefix string) (string, func(), error)`:
     * If prefix empty, use "ocrpdf-".
     * os.MkdirTemp("", prefix+"*"); on error return.
     * Return dir, a cleanup func that calls os.RemoveAll(dir), and nil error.

5. Verify: `go build ./internal/pdfio/...` and `go vet ./internal/pdfio/...` succeed, and `go mod tidy` leaves go.mod/go.sum consistent.

Do not add HTTP, OCR, or editing logic. Keep the package free of cross-imports with other internal packages.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file path -> pdfio | Caller-supplied paths (pdfPath, outDir, outputPath, imagePaths) cross into filesystem/pdfcpu operations. |
| PDF bytes -> pdfcpu | Scanned PDF content is parsed by pdfcpu; malformed input may error. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | pdfPath/outDir/imagePaths/outputPath | medium | mitigate | Reject empty paths; filepath.Clean all inputs; MkdirAll parent of outputPath; no path traversal beyond caller responsibility (containment enforced by Phase 4). |
| T-02-02 | Tampering | Extracted filenames from pdfcpu | low | mitigate | Parse only via anchored regexp; skip non-matching entries; never exec extracted files. |
| T-02-03 | Denial of Service | Large/malformed PDF causing huge extraction | medium | accept | Size/page caps enforced by Phase 4 API; pdfio itself surfaces pdfcpu errors. |
| T-02-04 | Information Disclosure | Temp directories left on disk | low | mitigate | NewTempDir returns a cleanup func; callers (Phase 4) remove per-document dirs; stale entries in outDir cleared at start of ExtractImages. |
| T-02-SC | Tampering | package installs | high | mitigate | pdfcpu v0.16.3 already approved in RESEARCH.md Package Legitimacy Audit; go.mod/go.sum updated via go get; no new unapproved packages. |

</threat_model>
